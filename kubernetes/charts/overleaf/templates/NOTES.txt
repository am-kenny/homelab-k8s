{{ $n = add1 $n }}{{ $n }}. Credentials:
  - This chart does NOT create the credentials Secret.
    It must already exist as "{{ $secret }}" in namespace {{ .Release.Namespace }}.
    Every key in it is passed to the container as an environment variable.

  - Two keys are required. The image refuses to start without them:
      OVERLEAF_SESSION_SECRET       signs session cookies
      OVERLEAF_INVITE_TOKEN_SECRET  signs invite and password reset tokens
    Both must stay stable. Regenerating either invalidates what it signed.

  - Create it with:
    kubectl create secret generic {{ $secret }} -n {{ .Release.Namespace }} \
      --from-literal=OVERLEAF_SESSION_SECRET="$(openssl rand -hex 32)" \
      --from-literal=OVERLEAF_INVITE_TOKEN_SECRET="$(openssl rand -base64 32)"

{{ $n = add1 $n }}{{ $n }}. First Start:
  - The first boot runs database migrations and can take several minutes.

  - Create the first admin account at /launchpad. That page is only open
    until an admin exists:

{{- end }}
